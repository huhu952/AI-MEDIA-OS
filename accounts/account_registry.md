# 账号档案（Account Registry）

唯一登记处：`accounts/account_registry.md`

## 维护规则

- 每次账号信息变化（昵称 / 简介 / 头像 / 状态 / 商业化等）即时更新，并更新“最近修改日期”。
- **禁止记录敏感信息**：身份证号、密码、Cookie、验证码、完整手机号、登录凭据。密钥只放环境变量或系统密钥管理器，绝不进入本仓库。
- 粉丝数为手动快照，注明采集日期；以平台后台实时数据为准。
- 发布、删除、修改平台内容或账号设置前，必须先获得人工授权。
