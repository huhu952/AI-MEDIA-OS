# AI 成本账本

记录每一次重要 AI 调用，用于回答：什么模型成功率最高、什么模型单位成本最低、
什么类型值得继续 / 停止。

判断模型优先看 **最终可用作品成本**，而不是单次生成价格。例如：模型 A 一次 2 元但平均抽
5 次才成功（10 元 / 成片），模型 B 一次 5 元但一次成功（5 元 / 成片），则模型 B 实际更便宜。

## 字段

| 字段 | 说明 |
| --- | --- |
| date | 调用日期 YYYY-MM-DD |
| project | 所属项目 / 作品 content_id（无则写任务名） |
| model | 模型 / 引擎名 |
| task | 任务：生图 / 生视频 / TTS / 转录 / 对话等 |
| generation_count | 生成次数 |
| success_count | 成功次数 |
| failure_count | 失败次数 |
| tokens_or_credits | Token 或积分消耗 |
| cost_rmb | 人民币估算成本 |
| adopted | 是否采用最终结果：yes / no / partial |
| notes | 备注（失败原因、参考图、抽卡次数等） |

## 记账规则

1. 每次生成类调用都记一行（批量可按批次记一行）。
2. **失败也要记**：失败成本是“最终可用作品成本”的一部分。
3. 高成本任务（视频生成、大批量生图）执行前先给用户报价 / 确认。
4. 月度可汇总：按 model / project 分组求和，结合内容实验库看 ROI。
