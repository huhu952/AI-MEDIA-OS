# 抖音短视频创作

## 输入
- 主题/脚本/素材：一句话选题或已有长视频/图文
- 可选：账号定位、目标时长（默认 15-60 秒）、参考爆款

## 输出
- 脚本（含分镜：画面+台词+字幕+音效+时长）
- 钩子方案（前 3 秒）
- 字幕文案（可直接做 srt）
- 发布清单（标题、话题、封面帧、发布时段、评论区话术）

## 执行流程
1. 定核心信息：一条视频只说一件事。
2. 写钩子：前 3 秒用冲突/悬念/结果/反常识抓人。
3. 分镜脚本：每 2-4 秒一个镜头，标注景别、动作、字幕、BGM 情绪。
4. 节奏控制：前 5 秒至少 1 次信息密度拉满，中段每 10 秒一个小爆点。
5. 字幕：口语化短句，一次一行，≤12 字/行。
6. 发布准备：封面选高信息帧，标题 20 字内，话题 3-5 个。

## 调用工具
- tools/video_analysis.py：分析对标视频（hook/节奏/镜头）
- faster-whisper：转录自己的口播稿做字幕
- ffmpeg：剪辑、加字幕、转码
- ai-screenwriter / ai-film-director：脚本与分镜

## 质量检查
- [ ] 前 3 秒有明确钩子（不依赖标题）
- [ ] 每句字幕 ≤12 字，口语化
- [ ] 有完整开头-冲突-结果结构
- [ ] 时长匹配平台偏好（<60 秒为佳）
- [ ] BGM/音效与情绪一致
- [ ] 封面帧信息完整、无遮挡主体

## 失败处理
- 完播率低：用 video_analysis.py 查 hook 与节奏，砍掉前 5 秒铺垫。
- 互动率低：结尾改为强指令提问（“你选哪个？评论区告诉我”）。
- 转码失败：检查 ffmpeg 路径与输出格式（h264+aac）。
