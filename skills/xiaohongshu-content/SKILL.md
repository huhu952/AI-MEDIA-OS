# 小红书内容创作

## 输入
- 主题/素材：产品、观点、经验、视频/图片素材或一句话想法
- 可选：目标人群、账号定位、竞品笔记链接

## 输出
- 笔记标题（3 个备选，含情绪词与关键词）
- 封面方案（主图+文案，配合 visual-agent 出图）
- 正文（600-1000 字，分段+emoji 适度+口语化）
- 话题标签（6-10 个，含 2-3 个垂直词 + 2 个泛流量词）
- 发布清单（配图数量、首图要求、发布时间、评论区引导）

## 执行流程
1. 明确人设与人群：决定口吻（教程/分享/避坑/故事）。
2. 定选题角度：痛点+解决方案，或反差+情绪，避免自嗨式介绍。
3. 写标题：数字、痛点、结果前置、悬念；检查是否像广告。
4. 写正文：开头 2 行抓人 → 干货分段 → 结尾互动提问。
5. 配图方案：首图信息量足、色彩统一；每张图说清内容。
6. 合规自检：不夸大功效、不放微信/引流词、不侵权。

## 调用工具
- web-research 技能：查平台热门趋势与竞品
- visual-agent / scene-visualizer：封面与配图
- content-data-analyst：历史数据复盘（如果已有账号数据）
- Playwright（授权后）：竞品笔记信息收集

## 质量检查
- [ ] 标题含具体数字或明确利益点
- [ ] 正文前 2 行有钩子
- [ ] 每段 3-5 行，有清晰小标题或分隔
- [ ] emoji 适量（每段 1-2 个），不刷屏
- [ ] 话题标签含垂直词 + 泛流量词
- [ ] 无违规词（医疗/金融夸大、导流、违禁词）
- [ ] 首图有文字信息且与标题呼应

## 失败处理
- 选题没灵感：用 web-research 抓 5 篇爆款，提炼共性角度再写。
- 数据不好（发布后复盘）：用 content-data-analyst 看点击率/互动率，改封面+前 2 行重发测试。
- 被判违规：删掉疑似导流/夸大词，对照平台规则逐条改。
