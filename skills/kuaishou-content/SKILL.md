# 快手内容创作

## 输入
- 主题/素材：生活记录、技能展示、农产品/实体店、同城信息
- 可选：是否带同城定位、是否有私域转化需求

## 输出
- 内容方案（口播稿/场景脚本）
- 拍摄与发布清单（封面、标题、话题、同城标签）
- 私域引导话术（合规版）

## 执行流程
1. 定真实感基调：快手用户偏好接地气、真实过程，避免精致假象。
2. 选题：生活技能、真实经历、同城故事、行业揭秘。
3. 脚本：口语化、短句、有“老铁”交流感，不端着。
4. 拍摄建议：自然光优先，展示过程而非只展示结果。
5. 发布：标题口语化+地域词，带同城标签；回复评论区建立信任。
6. 私域：合规引导（不直接放微信，用主页/直播间/粉丝群承接）。

## 调用工具
- ffmpeg：剪辑与转码
- faster-whisper：口播转字幕
- ai-screenwriter：脚本结构
- content-data-analyst：账号复盘

## 质量检查
- [ ] 内容真实可验证（有过程、有细节）
- [ ] 口吻自然，不像广告文案
- [ ] 标题含地域/人群/痛点关键词
- [ ] 同城标签已加（如适用）
- [ ] 无平台违禁词与导流硬广
- [ ] 时长合适（30-90 秒）

## 失败处理
- 流量低：检查是否被判定营销号，增加真实过程与互动引导。
- 私域违规：撤回硬广话术，改用粉丝群/直播承接。
- 素材不足：先用手机拍摄 3-5 条原生素材再剪辑。
