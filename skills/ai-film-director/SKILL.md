# AI 导演（分镜执行）

## 输入
- 剧本或故事大纲（ai-screenwriter 产出）
- 可选：参考片、角色设定图、场景参考、目标时长

## 输出
- 分镜表（镜头号/景别/角度/运镜/画面/台词/时长）
- 视觉一致性手册（角色、服装、场景、光线、色调固定描述）
- 每个镜头的生成提示词（配合 scene-visualizer / 生图 API）
- 成片验收清单

## 执行流程
1. 读剧本，定视觉基调（年代、色调、影调参考）。
2. 建立一致性锚点：每个角色固定“外貌+服装+标志物”描述，每个场景固定“环境+光线”描述。
3. 拆镜头：按情绪与信息量分配时长，避免一个镜头塞多动作。
4. 写分镜表并生成画面提示词（每镜一条，引用一致性锚点）。
5. 生成/拍摄素材，按分镜顺序拼接。
6. 验收：逐镜头对照锚点检查一致性，不合格的重做该镜头。

## 调用工具
- ai-screenwriter（剧本）
- storyboard-generator（分镜）
- scene-visualizer / 生图 API（场景图、角色图）
- 视频生成 API（如 Sora，以图生视频）
- ffmpeg（拼接、转场、字幕、音轨）
- tools/video_analysis.py（成片自检：节奏/Hook）

## 质量检查
- [ ] 角色外观在全部镜头中一致（无换脸/换装漂移）
- [ ] 镜头时长与情绪匹配
- [ ] 每个镜头只表达一个主要动作
- [ ] 光色统一（同场景同色调）
- [ ] 转场不跳戏，音画同步
- [ ] 成片前 3 秒有钩子

## 失败处理
- 角色不一致：回到一致性锚点重写该镜提示词，不靠后期硬修。
- 生成结果构图差：调整景别/角度描述，锁定参考图。
- 拼接违和：统一分辨率与帧率，先转码再拼接。
