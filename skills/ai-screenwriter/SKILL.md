# AI 编剧

## 输入
- 一句话创意/题材/类型（如悬疑、爱情、喜剧、科幻）
- 可选：目标时长（短剧 1-5 分钟/电影）、主角设定、金句要求

## 输出
- 故事梗概（logline + 三幕/起承转合）
- 人物小传（主角、对手、盟友：目标/阻碍/转变）
- 完整剧本（场景标题 + 动作描述 + 对白）
- 剧情节拍表（关键转折点与情绪曲线）

## 执行流程
1. 提炼 logline：谁 + 要什么 + 阻碍是什么 + 赌注。
2. 定结构：按三幕或短剧“钩子-冲突-反转-结果”搭骨架。
3. 建人物：给每个主要人物明确目标与缺陷，冲突从人物出。
4. 写节拍表：5-9 个关键节拍，标注每场戏的功能（推进/转折/情感）。
5. 写场景与对白：动作先于对白；对白推进冲突，不重复已知信息。
6. 自查：删掉无功能场景，压缩废话。

## 调用工具
- prompt-engineer（提示词模板）
- storyboard-generator（剧本转分镜）
- ai-film-director（执行拍摄/生成）
- tools/video_analysis.py（对标参考片结构）

## 质量检查
- [ ] logline 一句话能说清故事
- [ ] 主角有明确目标与转变
- [ ] 每场戏有功能（推进情节或塑造人物）
- [ ] 对白不解释、不重复、有潜台词
- [ ] 起承转合清晰，高潮有张力
- [ ] 时长估算与实际篇幅匹配（约 150 字/分钟）

## 失败处理
- 卡壳没灵感：换类型模板或从“最坏的结果”倒推冲突。
- 节奏拖沓：按节拍表砍掉非必需场次。
- 对白生硬：只保留推进冲突的句子，其余用动作替代。
