# 分镜生成

## 输入
- 剧本段落或场景描述
- 可选：时长、画幅（16:9/9:16/1:1）、风格参考、角色设定

## 输出
- 分镜表（镜头号、景别、角度、运镜、画面内容、台词、时长）
- 每个镜头的结构化画面提示词（scene-visualizer 模板）
- 一致性清单（角色/场景/光线固定描述）

## 执行流程
1. 读原文，拆信息单元：每个动作/情绪点一个镜头。
2. 定景别与角度：特写给情绪，全景给环境，俯仰给立场。
3. 标运镜：推/拉/摇/移/固定，一个镜头一种运镜。
4. 分配时长：默认单镜头 2-6 秒，情绪点可延长。
5. 写画面提示词：按“场景→主体→构图→光线→色调→禁忌”模板。
6. 输出一致性锚点清单，供后续所有镜头引用。

## 调用工具
- ai-screenwriter（剧本来源）
- scene-visualizer（画面提示词模板）
- ai-film-director（成片执行）
- 生图 API / ComfyUI（云端，如启用）

## 质量检查
- [ ] 每镜头一个主要动作
- [ ] 景别与情绪匹配
- [ ] 运镜明确且单一
- [ ] 台词/旁白与画面不重复
- [ ] 提示词含场景、主体、构图、光线、色调
- [ ] 角色/场景锚点在跨镜头保持一致

## 失败处理
- 镜头太多难生成：合并同机位连续动作，减少镜头数。
- 画面与预期不符：检查提示词是否缺“光线/构图/禁忌”，逐项补全。
- 分镜与台词脱节：以台词为准重排画面顺序。
