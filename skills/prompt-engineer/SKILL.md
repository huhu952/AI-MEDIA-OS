# Prompt 工程

## 输入
- 目标类型：图像/视频/文本/数据分析
- 需求描述（一句话即可），可选：风格参考、负面清单、输出格式

## 输出
- 结构化提示词（分场景/主体/构图/光线/色调/约束/禁忌）
- 迭代版本（v1 基线 → 问题定位 → v2 修正）
- 可复用的提示词模板（存入 prompts/）

## 执行流程
1. 明确用途：同一主题用于封面/分镜/海报，提示词写法不同。
2. 按模板组装：场景 → 主体 → 细节 → 构图 → 光线 → 风格 → 文字 → 约束。
3. 加负面约束：明确写“不要什么”（水印、多余角色、文字乱码）。
4. 迭代：一次只改一个变量，保留有效部分，记录差异。
5. 沉淀：把验证有效的提示词存到 prompts/ 模板库。

## 调用工具
- scene-visualizer（图像场景提示词模板）
- storyboard-generator（分镜提示词）
- ai-film-director（视频生成提示词）
- ai-screenwriter（文本/对白提示词）
- 生图/视频 API（云端）

## 质量检查
- [ ] 提示词包含场景、主体、构图、光线、色调五个基础要素
- [ ] 有明确负面约束
- [ ] 文字内容使用原文引用（不靠模型猜测拼写）
- [ ] 一次迭代只改一个变量
- [ ] 结果可复现（参数与模型已记录）

## 失败处理
- 结果不稳定：固定 seed/参考图，减少随机性。
- 内容不符合预期：检查是否缺少关键约束，拆成更小单元分步生成。
- 文字错乱：提示词逐字拼写文字内容，或用后期覆盖。
